# 42NAV

Landing page for 42NAV — telecom, mobility & cloud advisory.

Live site (once GitHub Pages is enabled): https://42sagiv.github.io/42nav/

## Structure

- `index.html` — single-file landing page (HTML/CSS/JS, no external dependencies)

## Local preview

Just open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

then visit `http://localhost:8000`.
